## Learning notes

- Keep Terraform configuration, variables and outputs clearly separated.
- Use typed variables and validation rules.
- Never commit credentials, state files or real `terraform.tfvars`.
- Run `terraform fmt`, `terraform init` and `terraform validate` before planning.
- Review the full plan before any cloud operation.
